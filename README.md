# Rasoira — Aaj Kya Banayein

Indian home-cooking app: **900+ recipes**, photos, Aaj Kya Banaye, pantry search, cooking mode + voice.

**Public repo:** https://github.com/Niravbodana/dangerai.com

## Quick start (Mac)

```bash
git clone https://github.com/Niravbodana/dangerai.com.git
cd dangerai.com/aaj-kyabanayein
npm run install:all
```

**Terminal 1 — API**
```bash
npm run dev:server
```

**Terminal 2 — App**
```bash
npm run dev:client
```

- Mac browser: http://localhost:3000  
- Phone (same Wi‑Fi): `http://<your-mac-ip>:3000` — IP: `ipconfig getifaddr en0`

Full docs: [aaj-kyabanayein/README.md](./aaj-kyabanayein/README.md)

## What's included (latest `main`)

- 900+ curated recipes (Indian + TheMealDB + DummyJSON)
- Homepage mood plans + quick 20-min meals
- Fast `npm install` (no API fetch on install)
- Phone access on same Wi‑Fi
- Cooking mode, Hindi/English voice, favorites, collections, pantry
- Today plan, streak, taste profile, Plus pricing UI
